## 1. 坐标与命名约定（先看这个）

数据用 `x`（沿 270 m 长轴）、`z`（横向，**z 越小越靠北**）、`level`（1–7）定位，单位 m。

```
        z=+20 ┌────────────────────────────────────┐  ← 3d.html 楼板南缘（宽 40 m 上限）
              │                                    │
   z=+8     南 │  ▣ ▣ ▣ ▣   教室（单侧、全部在南）   │  ← 房间中心（估算）
              │                                    │
   z=0      走 │ ─────────── 走廊 ────────────────  │  ← 走廊中心（估算）
              │                                    │
   z=-8     北 │ ▥ 楼梯 / 空位 / 电梯井（服务带）     │  ← 服务带中心（估算），不是教室
        z=-20 └────────────────────────────────────┘
                     ⋯ 42 m 空档（未建模）⋯
        z=-50     ══════ 北楼走廊（仅 4F/5F）══════
       z=-54.5    ▣ ▣ ▣ ▣ ▣ 北楼教室（仅 4F/5F，5 间/层）
```

- `x` 方向：数据**没有声明** x 递增是"东"还是"西"。实测 6 个南侧入口里名字带"东侧"的 `x=50.62…135`、带"西侧"的 `x=185.62…219.38`，即 **x 小的一侧是"东"**（从命名反推，非字段）。
- `x` 共 **25 个取值**：`0, 16.88, 33.75, 50.62, 60, 67.5, 75.6, 84.38, 91.2, 101.25, 106.8, 118.12, 122.4, 135, 151.88, 168.75, 185.62, 199.5, 202.5, 205.5, 219.38, 236.25, 253.12, 265.78, 270`。其中 **199.5 / 205.5 是 321/324 的估算位**，不在 16.875 列距上（`202.5 ∓ 3`）。
- `elevation` 按 40/7 逐层取整两位：`0 / 5.71 / 11.43 / 17.14 / 22.86 / 28.57 / 34.29`。
- `displayY` = 3D 堆叠高度：`2.2 + (level-1) × 6.0`，**层间 6 m ≠ 层高 5.71 m**，纯示意。
- `type`：`room` / `corridor` / `stair`（图纸楼梯间）/ `stair_core`（楼梯柱）/ `void`（空位）/ `elevator` / `entrance`。
- **每间教室只连 1 个走廊节点**（80/80 实测度=1），横向连通靠走廊链边；"走廊"在数据里是**每列一个离散点**。
